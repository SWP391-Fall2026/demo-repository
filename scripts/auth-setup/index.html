Kết nối Supabase staging

Điền trên máy của bạn, tải file cấu hình riêng, rồi gửi chỉ đường dẫn file trong chat.

Form không gửi giá trị nhập lên server/API và không dùng localStorage. File tải xuống chứa secret dạng văn bản: cất ngoài Git, không tải lên chat. Form không khởi chạy backend hoặc kiểm tra kết nối.
1. Database đã xác nhận

Kết nối direct theo thông tin bạn đã cung cấp. Không nhập API key/service_role key hoặc URL có mật khẩu vào ô host.

2. Backend và frontend

Kiến trúc hiện tại: Spring Boot JWT + public.users; React chỉ gọi backend. Password đăng ký giữ nguyên, tối đa 72 byte UTF-8.

3. SMTP nếu dùng email thật

Cấu hình email dùng STARTTLS bắt buộc. Nếu nhà cung cấp cần cách kết nối khác, báo lại trước khi chạy.

File luôn giữ ddl-auto=validate, scheduler tắt và AUTH_SCHEMA_REVIEWED=false. Chỉ sau khi xác minh metadata mới bật đăng ký. Form không thay schema, RLS, privilege hay dữ liệu.
